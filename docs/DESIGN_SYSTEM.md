# Design system · Mission Poster

Modelled on NASA and JPL mission posters: one continuous black sky, planets lit hard from the upper left, no boxes around the art.

## Colour

| Token | Hex | Use |
|---|---|---|
| `sky` | `#0B0B0C` | Every background |
| `text` | `#D5D5CA` | Primary text |
| `muted` | `#868077` | Labels |
| `lime` | `#D8F558` | One action per screen |
| `bronze` | `#9E7F60` | Earned things |
| `salmon` | `#F3A080` | Warnings only |
| `planet-shine` | `#8CBDFF` | Limb glow, ship rim light |

Hairlines are `#D5D5CA` at 18 to 28 percent.

## Type

- Tomorrow ExtraLight, uppercase and tracked wide, for names and titles.
- The system monospaced font, small and tracked, for labels and readouts.

## Rules

- One lime element per screen, and it is the action.
- Chamfered bezels for controls; circles only for planets, stars and the settings key.
- Drawn glyphs only. No emoji.
