# Repo setup

1. Create a public repo named `kazi-focus`.
2. Open the unzipped `kazi-focus-github` folder, select everything inside it, and drag those items (not the folder) onto "Add file → Upload files". Commit message: `Add public page for KAZI Focus`.
3. Settings → General → Social preview → upload `media/social-preview.png`.
4. About (gear icon):
   - Description: `Space-themed focus timer for iPhone · live Metal planets · RealityKit ships · Live Activity + widgets · 100% on device · by Shahzada Shah`
   - Website: the App Store link
   - Topics: `swift`, `swiftui`, `ios`, `iphone-app`, `metal`, `shaders`, `realitykit`, `3d`, `activitykit`, `live-activities`, `widgetkit`, `app-intents`, `gamification`, `focus-timer`, `pomodoro`, `productivity`, `privacy-first`, `design-system`
   - Untick Releases, Packages and Deployments.
5. Pin the repo on your profile.

Source boards: `KAZI Focus GitHub Showcase.dc.html` in the design project.
